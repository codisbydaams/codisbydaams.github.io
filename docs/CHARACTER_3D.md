# CODIS-V71 · الشخصية ثلاثية الأبعاد (3.58.0)

## النطاق
إنشاء الشخصية وحفظها وإدارتها فقط. لا تظهر في أي غرفة أو تقويم أو شريط، ولا مساعد/تذكيرات/محادثات (مرحلة لاحقة).

## الأصول
- Quaternius «Universal Base Characters [Standard]» — CC0 1.0 (`tools/char3d/SOURCE_AND_LICENSE.md`).
- جسمان كاملان (ذكر/أنثى) بهيكل UE (65 عظمة: عمود فقري، أذرع، أصابع، أرجل) + عينان + حاجبان.
- تسريحات مجسّمة: جانبية · قصيرة جداً · طويلة · كعكتان · قصيرة (أنثوية) + لحية.
- البناء: `tools/char3d/make_textures.py` ← `build_assets.mjs` ← `dist/*.glb` (ذكر ~808KB، أنثى ~810KB، شعر ~525KB) ← مدفونة base64 بنهاية الصفحة.

## العرض (`tools/box3d/src/char.js` → `CodisB3D.char.create(host, opts)`)
- داخل حزمة `#codis-b3d-src` نفسها (Three r170 + GLTFLoader r170). أول من يحتاجها (الصناديق أو الشخصية) يشغّلها؛ الآخر يعيد استعمالها.
- `setConfig({body, face:{id,p}, hair:{mesh,beard,native}, color})` · `setZoom(0..1)` (0 الجسم كاملاً، 1 الوجه) · `rotateBy(rad)` · `snapshot(cfg, {z,size,yaw})` (لقطات البطاقات من المجسّم نفسه) · `dispose()`.
- الكاميرا تُحسب من صندوق الجسم بعد الوضعية ونسبة الشاشة ⇒ لا قصّ من الأعلى/الأسفل/الجانبين (مُختبر بإسقاط الصندوق).
- الحلقة: rAF فقط والعارض ظاهر والصفحة أمامية (IntersectionObserver + visibilitychange)؛ الخمول بنصف المعدل؛ تقليل الحركة ⇒ بلا تنفّس.
- `webglcontextlost/restored` مُعالجان؛ بلا WebGL ⇒ رسالة واضحة ويبقى الاختيار والحفظ متاحين.
- دقة البكسل ≤2 (≤1.5 للأجهزة الضعيفة أو بعد فقدان سياق في `codis_b3d_health`) ضمن ميزانية 2.6MP.

## البيانات والمزامنة
`data.profile.character = { v:1, body, face, hair, color, model:'ubc-std', assets:'v71-1', createdAt, updatedAt }` + `data.profile.charOfferedAt` («لاحقاً»).
الحفظ عبر `saveData()` (المحلي + مرآة IndexedDB + `CodisAccount.noteChange` ⇒ لقطة المزامنة). لا تغيير بـSupabase/SQL/RLS: الحقل جزء من اللقطة الحالية.
