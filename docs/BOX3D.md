## المجسّمات (لا GLB: هندسة JS حقيقية)
`models.js::buildBox(n)` يبني كل مستوى بهندسة مستقلة: جسم **مجوّف** (جدران بسماكة + أرضية + تبطين داخلي)، غطاء بسماكة وسطح داخلي وشفة، **مفصلتان على محور الغطاء الحقيقي** (`lidPivot` عند حافة الظهر العليا)، قفل (لسان يتحرر قبل الفتح)، زخارف، وخيط تسريب ضوء عند الدرزة. ثم تُدمج الأجزاء الساكنة حسب الخامة (بضع مشابك رسم/صندوق) وتبقى الأجزاء المتحركة منفصلة. الخامات من Canvas صغير (ورق/جلد/حجر/معدن مصقول) — لا صور.
1. برونزي: كرتون بني بشرائط وأزرار نحاسية، غطاء مسطح. 2. فضي: جلد كحلي + إطار فضي + غطاء مقوّس بأضلاع. 3. كريستال: حجر داكن طويل + بلّورات زرقاء. 4. ذهبي: جلد أحمر + نحاس + شرائط سوداء. 5. أسطوري: ثماني على قاعدة مدرّجة + أعمدة ذهبية + أجنحة + تاج بلّوري.
`instantiate()` ينسخ المجسّم مشاركاً الهندسة والخامات الثابتة (×10 = عشر نسخ بغطاء مستقل لكل واحدة؛ خامات التوهّج/الجواهر فقط تُنسخ).

## المشهدان (إخراجان مستقلان فوق `Runner` واحد)
- `single.js`: دخول (سقوط + ضغط) ← تقديم (دوران محدود) ← ترقّب (تسريب ضوء، اهتزاز يتصاعد، شرر، قفل) ← فتح بقفزة قفل ثم دوران الغطاء مع ارتداد استقرار ← خروج البطاقة من التجويف ← لقطة بطل ← تسليم.
- `bulk.js`: عشر نسخ على منصّة معرض (تخطيط 3-4-3 للهاتف الطولي، 4-3-3 للمتوسط، 5+5 للعريض)، سقوط متتابع، فتح بترتيب `econBulkOrder` (الأفضل أخيراً وبمنتصف الصف الأمامي مع لحظة هدوء قبله)، كاميرا لكل صندوق، وكل بطاقة تطير لخانتها بصف النتائج بحسب **رقم الصندوق الأصلي**؛ ثم التسليم لشبكة النتائج الأصلية.
- **مستوى الكشف** (`CodisRevealLevels` من القيمة الفعلية) → مجموعة g (1..5) تغيّر الإخراج نفسه: مدد الترقّب/الفتح، مسار الكاميرا (رافعة منخفضة + دوران + دولي-زوم)، الكسوف (خفت الإضاءة قبل الفتح)، إبطاء الزمن، حلقة صدمة، أشعة، ارتجاج. **مستوى الصندوق** يغيّر المجسّم/الخامات/ألوان الضوء فقط.

## البطاقة = بطاقتك الفعلية
البطاقة التي تخرج من الصندوق (وتطير لصف النتائج في ×10) هي **نفس عنصر DOM لبطاقة الجائزة** (نفس HTML/الصورة/الإطار/الخط/الندرة؛ مظهر/عطلة/تجاوز/كيس فضة كلٌّ بوجهه) المبنية من نفس دوال نافذة النتيجة (`faceOf` بالجسر ← `econBoxRewardArt/codisPassCardHtml/hcdCardHtml/econCosmeticPreviewHtml/econPouchSvg`). `dom.js` يسقط عليها تحويلاً منظورياً (homography ← `matrix3d`) من أركان مستوى البطاقة ثلاثي الأبعاد عبر كاميرا المشهد، ويعرض ظهراً عاماً حين تدير ظهرها، ويقصّها بخط حافة الصندوق الأمامية فتبدو خارجة من داخله. الرسم البديل (Canvas) يبقى احتياطاً فقط إن تعذّر بناء الوجه.

## ملء الشاشة والسلامة
- الطبقة `.b3d-root` مثبّتة على `documentElement` (خارج تحويل body) بـ`inset:0` وz-index أعلى كل شيء؛ `body.inert` أثناءها (لا تفاعل/تركيز/قارئ شاشة) و`overflow:hidden`. لا أزرار مرئية.
- **تخطٍّ خفي**: نقرتان سريعتان على المشهد أو Esc ← تسليم فوري. الرجوع/الإغلاق الخارجي (`econBoxClose/econBulkClose`) يُنظّف كل شيء.
- **أي فشل** (لا WebGL، خطأ بالمشهد، فقد السياق، تعطل الخط الزمني) ← `handoff` فوراً فتصل المكافأة؛ وحارس زمني في الجسر (`watchdog`). بلا WebGL أو بفشل تحميل المحرك يعمل مشهد 2D القديم كما كان (`CodisBoxCinema`/`CodisBulkCinema` لم يُحذفا). **ليست لقطات مُصيَّرة مسبقاً من النماذج** (لم تُنفَّذ).
- تقليل الحركة: نسخة قصيرة (دخول هادئ + فتح قصير + بطاقة) للواحد وللـ×10 بدل القفز للنتائج.
- التنظيف: `Runner.dispose` يلغي rAF والمستمعين و`ResizeObserver` ويتخلص من الهندسة/الخامات/الـRenderer (`forceContextLoss`) ويعيد `inert/overflow`.
- الجودة: `quality(low)` — `low` = `hardwareConcurrency ≤ 4` أو `deviceMemory ≤ 2`: بلا antialias، ظلال 1024، جسيمات أقل، DPR أقل؛ سقف بكسلات للـcanvas.
